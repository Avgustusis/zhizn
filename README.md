# Жизнь — цифровая версия

Настольная игра «Жизнь» в браузере: одна страница для компьютера и телефона, играть по ссылке.
Автор и геймдизайнер — Август. Код пишет Claude.

## Где что лежит

| Папка | Что там |
|---|---|
| `src/data/` | Карты в цифровом формате: схема (`schema.ts`), колоды (`decks/*.json`), пересказ разбора (`render.ts`) |
| `src/engine/` | Движок правил (появится на этапе 2) |
| `src/App.tsx` | Сейчас — просмотрщик колод для проверки перевода карт |
| `tools/` | Сборка колод из документа колод |
| `tests/` | Автопроверки: схема карт, имена предметов, кубики, сложности |
| `docs/` | Архитектура, формат карт, решения по правилам |
| `reference/` | Снимки документов на 11.11.2026, книга правил, движок-симуляция на Python, макеты компонентов. Только для справки |

## Команды

Нужен Node.js 22+.

```bash
npm install        # один раз
npm run dev        # сайт на компьютере: http://localhost:5173
npm test           # автопроверки
npm run check      # типы + проверки + линтер
npm run build      # сборка сайта в dist/
```
