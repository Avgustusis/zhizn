| 26.11.2026 | Экран, вторая порция (замечания Августа) | В листе — положения культуры (сильные, затем умеренные, с поправкой идеологии страны). Окна «что вышло»: решение Рынка молодости (всегда), покупка на рынке с проверкой или предметом, новый знакомый (его карта), уход с фронта (комиссия и др.). У «остаться» в окнах войны и бегства — подпись о призыве: неизбежен / D6 1–N / не призывают и почему; рядовым или офицером. Условия со своими вариантами («Есть Партнёр: А) … Б) …») — по строкам, скобки не рвутся; разбор эффекта вариантов — фразой, не столбиком; пояснения к вариантам — обычным шрифтом. Гражданство враждебной страны легального выезда туда не даёт (концепция, «Отношения стран»: при вражде легально нельзя) — вопрос соавтору |
| 26.11.2026 | Экран: текст карт и журнал (замечания Августа) | Правило карты — по строкам: каждое условие (полюс, идеология, класс, D6, успех/провал, «иначе») с новой строки, подпись группы («Страна:», «Игроки:», «🎲 …:», «А) …:») слева. Варианты без «А) Б)» — словами карты из скобок. Имя игрока — один раз. Журнал объясняет число не как на карте («по карте −1, сильное положение «Секуляризм» −1, возраст: Детство −1»); бросок читается «нужно 12: кубики … = 8, Ловкость +5, поправки −1 → 12». «Сокращение» (Детство № 45): формулировка Августа — «Если класс семьи…: класс семьи становится Народ… Иначе: отца сократили…» (внести в документ колод) |
| 25.11.2026 | Гражданство для выросших в стране (соавтор) | Кто приехал с семьёй до Молодости, на входе в Молодость получает гражданство страны без Стажа и проверки; гражданство страны рождения остаётся (двойное). Сильный Этноцентризм страны (−2): нужна аккультурация 2+, иначе 🎲 Смекалка 10; не прошёл — натурализация по взрослым правилам. Цифровая версия: союз со страной рождения — тоже без проверки (как у взрослых); «Без документов» — не получает; гражданство страны рождения теряется, если двойное запрещает любая из двух стран — новая или страна рождения (Национализм, Военная диктатура; соавтор, 26.11). Порядок входа в Молодость: аккультурация → гражданство выросшего → натурализация → «Присяга» |

Герой человека — по шагам концепции с «Долей»; герои ИИ — по архетипам. Шаг 4: классы выбирают (решение 23.11) — текст концепции поправить |

## Открытые вопросы по картам

Вопросы к конкретным картам хранятся в самих картах (поле `doubts`) и видны в просмотрщике с флажком «только спорные».
Когда Август отвечает, разбор карты правится, а вопрос удаляется.
