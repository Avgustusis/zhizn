# Решения по правилам для цифровой версии

Решения Августа, принятые при переносе. Новое — сверху.

| Дата | Вопрос | Решение |
|---|---|---|
| 11.11.2026 | Несколько «d6» на одной карте | Один бросок на карту, все части читают один результат (числа — таблица исходов). Отдельные броски — только у проверок 🎲 и где карта прямо говорит «каждый отдельно» |
| 11.11.2026 | «Друг» на картах | «Друг детства» тоже считается Другом. Друзей несколько — кого терять, выбирает игрок. Тень «Друга детства» (1–4) — только при эмиграции |
| 11.11.2026 | «Письмо в будущее» (Юность № 39) | Проверяется после последнего броска на смысл при входе в Зрелость |
| 11.11.2026 | «d6 6 — +1 Мудрость; в культуре X ещё +1 псих.» | Бросок относится только к Мудрости (её рост из событий урезан и стоит «на 6»). Бонус культуры после «;» безусловный |
| 11.11.2026 | География стран | Её задаёт основная культура: Большое озеро — Карвенцы или Олейцы, болота — Эшвины, ледник — Сарды. Карта мира не нужна |
| 11.11.2026 | Летопись в «Поколении» | Отметки видам — только в «Роде», на картах пометка «(только «Род»)». В «Поколении» эта часть пропускается, медведь из Древности (№ 30) никогда не спасён |
| 11.11.2026 | «Диаспора без своих» | Культуры игрока нет в стране ни как основной, ни как меньшинства. Обряд не срабатывает, только −1 псих. |
| 11.11.2026 | «Переболел» (Детство № 4) | Был просто текстом, с карты убран; иммунитета в игре нет |
| 11.11.2026 | Шесть систем, которых нет в Python-симуляции: оси характера, бонусы предметов по тегам, «Верхи» и «Дно», полный Рынок молодости, модификаторы культуры, правило привилегий | Делаем в первой версии: на них ссылается текст карт. Баланс после этого перепроверяем сверкой с симуляцией |
| 11.11.2026 | С какого отрезка работает взрослый рынок | С Молодости, как в симуляции. Надпись «со Зрелости» на планшете «Рынок» — устаревшая |

## Открытые вопросы по картам

Вопросы к конкретным картам хранятся в самих картах (поле `doubts`) и видны в просмотрщике с флажком «только спорные».
Когда Август отвечает, разбор карты правится, а вопрос удаляется.
