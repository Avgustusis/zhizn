# Поправки к проверкам по тегам

Этот файл печатается из `src/data/tables.ts` командой `npx tsx tools/print-modifiers.ts`. Править нужно таблицы, а не его.

**Черновик: ждёт утверждения Августа.** В концепции эти таблицы написаны прозой («+ к карьере и статусу; − к обращению за помощью»).
Движку нужны знаки по тегам, поэтому проза переведена в таблицу. Где концепция говорит о механике, а не о броске
(«катастрофы мягче на 1», «банк дешевле»), строки нет: это отдельные правила этапа 3.

Как читать: «+ #карьера» — к проверке на карте с тегом #карьера прибавляется сила положения: 1 при «умеренно», 2 при «сильно».
«−» — вычитается. Все ситуативные поправки вместе — не больше ±3.

## Культура игрока

Берётся профиль культуры игрока (у бикультурного — личная культура) с поправкой идеологии страны.
На картах колоды «Культура» эти поправки не действуют: там полюса расписаны на самой карте.

| Ось | Первый полюс | Второй полюс |
|---|---|---|
| Коллективизм ↔ Индивидуализм | + #община<br>− #карьера<br>− #своёдело | + #карьера<br>+ #своёдело<br>− #община<br>− #старение |
| Иерархия ↔ Равенство | + #связи<br>+ #бюрократия<br>− #заслуги | + #заслуги<br>− #связи |
| Патриархат ↔ Матриархат | + #гендер (полу в преимуществе)<br>− #гендер (полу в помехе)<br>− #помощь (полу в преимуществе) | + #гендер (полу в преимуществе)<br>− #гендер (полу в помехе)<br>− #помощь (полу в преимуществе) |
| Порядок ↔ Риск | + #работа<br>− #своёдело | + #своёдело<br>+ #эмиграция |
| Теизм ↔ Секуляризм | + #утрата<br>+ #вера | + #помощь<br>− #утрата<br>− #вера |
| Традиция ↔ Самовыражение | − #раскрытие | + #культура |
| Фамилизм ↔ Институции | + #семья<br>+ #связи<br>− #помощь | + #помощь<br>− #семья |
| Доверие ↔ Цинизм | + #сделка<br>+ #доверие | − #сделка<br>− #доверие<br>+ #бюрократия |
| Честь ↔ Достоинство | + #конфликт<br>+ #насилие | + #закон<br>− #насилие |
| Материализм ↔ Гуманизм | + #статус | + #образование<br>+ #дружба<br>+ #культура |
| Этноцентризм ↔ Открытость | — | — |

## Характер

| Ось | Первый полюс | Второй полюс |
|---|---|---|
| Самолюбие ↔ Скромность | + #карьера<br>+ #статус<br>− #помощь<br>− #дружба | + #дружба<br>+ #помощь<br>− #карьера |
| Хватка ↔ Щедрость | + #сделка<br>+ #собственность<br>− #любовь<br>− #дружба | + #община<br>+ #дружба |
| Влюбчивость ↔ Верность | + #любовь (нет пары)<br>− #здоровье<br>− #конфликт | + #любовь (есть пара)<br>− #любовь (нет пары) |
| Соперничество ↔ Участие | — | + #дружба<br>+ #община |
| Аппетит ↔ Мера | — | + #здоровье<br>+ #старение |
| Вспыльчивость ↔ Выдержка | + #конфликт (проверка Сила)<br>+ #насилие (проверка Сила)<br>− #закон | + #закон<br>+ #бюрократия<br>+ #любовь<br>− #конфликт (проверка Сила)<br>− #насилие (проверка Сила) |
| Беспечность ↔ Усердие | − #работа<br>− #образование | + #работа<br>+ #образование<br>+ #карьера |

Полюса без строк (Соперничество, Аппетит) работают особыми правилами, а не поправкой к броску.

## Идеология страны проживания

Поправка ±1 всем, кто живёт в стране (или только названным).

| Идеология | Поправки |
|---|---|
| Либеральная демократия | +1 #политика<br>+1 #заслуги<br>−1 #бедность |
| Социал-демократия | +1 #бедность<br>+1 #здоровье<br>+1 #образование |
| Теократия | +1 #вера<br>+1 #община<br>−1 #раскрытие |
| Национализм | +1 #статус (большинству)<br>−1 #чужак |
| Госсоциализм | +1 #работа<br>+1 #образование<br>−1 #своёдело<br>−1 #эмиграция |
| Военная диктатура | +1 #война (классу Армия)<br>−1 #политика<br>−1 #медиа |
| Клептократия | +1 #связи<br>−1 #заслуги |

Сдвиг положения культуры на 1: Теократия — к полюсу «Теизм»; Национализм — к полюсу «Этноцентризм»; Клептократия — к полюсу «Цинизм».

## Класс

Теги класса: членам доминирующего класса в них преимущество, членам отчуждённого — помеха.

## Мода

Раса в моде: +1 в проверках с тегами #тело #любовь #статус; не в моде — −1.
