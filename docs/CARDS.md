# Формат карт

Каждая колода — файл `src/data/decks/<имя>.json` (латинские имена файлов — в `DECK_FILES` схемы). Точная схема — `src/data/schema.ts`, она же проверяет файлы.

## Карта

```json
{
  "id": "возраст.детство.04",
  "n": 4,
  "title": "Детская инфекция",
  "text": "Вся улица болеет одним и тем же.",
  "src": "🎲 Выносливость 12 (на периферии 15): успех — +1 Выносливость, переболел; провал — −3 физ.",
  "kind": "П",
  "sub": ["М"],
  "tags": ["#здоровье"],
  "effect": [ ... ],
  "doubts": ["вопрос к автору"]
}
```

| Поле | Что это |
|---|---|
| `id` | Колода и номер карты в документе |
| `title`, `text` | Название и художественный текст, дословно из документа колод |
| `src` | Оригинальный текст эффекта, дословно. По нему сверяют разбор |
| `kind` | Б — просто бывает, П — проверка, Р — решение |
| `sub` / `segs` | Подсекторы (колоды Возраста) или отрезки (общие колоды) |
| `tags` | 1–2 тега из каталога. По ним движок сам добавляет поправки культуры, характера и предметов |
| `miracle` | Карта-чудо |
| `requires` | Условие карты («Только со статусом «Диплом»…»): не выполнено — карта в сброс, тянут следующую |
| `cancelBy` | Козыри, которые отменяют карту целиком |
| `effect` | Разбор: список шагов, выполняются по порядку |
| `doubts` | Вопросы к Августу. Пока они есть, карта считается спорной |

## Шаги эффекта

| Шаг | Пример | Значит |
|---|---|---|
| `add` | `{"add": {"Харизма": 1, "псих": -1}}` | Изменить числа. Возрастной сдвиг к физ. и псих. движок добавляет сам |
| `addOneOf` | `{"addOneOf": ["Сила", "Ловкость"], "n": 1}` | +n к одной характеристике на выбор игрока |
| `addUsed` | `{"addUsed": 1}` | +n к характеристике, которой бросал проверку («успех — +1 к ней») |
| `addPredisp` | `{"addPredisp": 2}` | +n к характеристике предрасположенности |
| `addClassStat` | `{"addClassStat": 1}` | +n к характеристике пригодности своего класса (на выбор; `both` — к обеим) |
| `installments` | `{"installments": 4, "each": [...]}` | Платежи на входе в каждый следующий подсектор (половину отрезка) |
| `everySeg` | `{"everySeg": [...]}` | До конца жизни, в начале каждого отрезка |
| `set` | `{"set": {"возм": -10}}` | Установить значение |
| `term` | `{"term": -2}` | Институт: срок ±n ходов |
| `release` | `{"release": true, "noStigma": true}` | Институт: выйти сейчас (без стигмы выхода) |
| `workoff` | `{"workoff": 3}` | Кабала: отработка даёт n вместо +2 до конца срока |
| `stab` | `{"stab": -2}` | Стабильность страны ±n |
| `halve` | `{"halve": "возм"}` | Потерять половину возможностей (вниз) |
| `miracle` | `{"miracle": ["Ловкость"]}` | Чудо: +2, гриф вскрыт |
| `gain` / `lose` | `{"gain": "Друг детства"}` | Получить или потерять предмет из каталога (`blind` — вслепую; у `lose` `price` — с обычной ценой сброса: «Партнёр уходит» без уточнения — всегда с ценой, «без цены» — только где написано) |
| `income` | `{"income": 2, "until": "отрезок"}` | Прибавка к доходу до конца отрезка |
| `pension` | `{"pension": 1}` | Надбавка к пенсии до конца жизни, по правилам пенсии |
| `reshuffle` | `{"reshuffle": true}` | Карта замешивается обратно в колоду |
| `noAging` | `{"noAging": 2}` | Древность: столько ходов без ежеходной потери физ. |
| `charStep` | `{"charStep": "Вспыльчивость"}` | Характер на шаг к полюсу |
| `cls` | `{"cls": "Интеллигенция"}` | Смена класса; ключи старого класса гаснут, «Диплом» остаётся |
| `allowCls` | `{"allowCls": "Мафия"}` | «Разрешено перейти в класс …»: решение сразу, при розыгрыше, позже нельзя |
| `later` «выход из тюрьмы» | `{"later": {"when": "выход из тюрьмы", "then": [...]}}` | Эффект после выхода из тюрьмы |
| `prison` | `{"prison": "лёгкое"}` | Тюрьма: лёгкое — d3 хода (по умолчанию), тяжёлое — d6 + 2, только где карта пишет «(тяжёлое)» |
| `check` | `{"check": {"stat": "Сила", "dc": 12}, "success": [...], "failure": [...]}` | Проверка 3d6 + характеристика ≥ сложности |
| `choose` | `{"choose": [{"label": "ясли", "then": [...]}, ...]}` | Решение игрока; у варианта может быть условие `if` |
| `d6` | `{"d6": {"1-2": [...], "6": [...]}}` | Исходы d6; на пропущенных значениях ничего не происходит. **На карту — один бросок:** все параллельные шаги `d6` читают один результат; `d6` внутри исхода другого `d6` бросается заново |
| `if` | `{"if": условие, "then": [...], "else": [...]}` | Условие |
| `cases` | `{"cases": [{"if": ..., "then": [...]}, ...], "else": [...]}` | Первая подходящая ветка («Ядро: … Периферия: …») |
| `mod` | `{"mod": {"tag": "#статус", "add": -1, "until": "отрезок"}}` | Временная поправка к будущим проверкам; `"fork": "Образование"` — к проверке на развилке |
| `later` | `{"later": {"when": "вход в Зрелость", "then": [...]}}` | Отложенный эффект; `"until": "отрезок"` — только если событие случится до конца отрезка |
| `cancelable` | `{"cancelable": ["Знакомый врач"], "then": [...]}` | Шаги, которые игрок может отменить, потратив козырь |
| `useTrump` | `{"useTrump": ["Знакомый врач"], "then": [...], "else": [...]}` | Игрок решает, тратить ли козырь: `then` — потратил, `else` — нет. Козыри одноразовые, связи и статусы — нет (для них `if` + `has`) |
| `flag` | `{"flag": "…"}` | Отметка в журнале жизни (для смыслов и будущих карт) |
| `rule` | `{"rule": "обряд"}`, `{"rule": "летопись", "arg": "мшистый бык −1"}` | Особое правило, которое выполняет код (список — в `RULES` схемы) |
| `bottom` | `{"bottom": true}` | Карта уходит под низ колоды |
| `say` | `{"say": "вакцину не довезли"}` | Текст без механики для журнала |

## Колода «по полюсам» (Культура)

У файла колоды флаг `"polar": true`. Числа в ветках с условием `culture` (без `strong`) и на картах с `requires: {culture}` записаны для «умеренно»; при «сильно» движок делает на 1 крупнее только псих., физ. и возм. (+1 → +2, −2 → −3; смягчение тоже растёт). Сплочённость, характеристики, d6, сложности и бонусы не растут. Поправки по полюсу в `mods` записаны для «сильно» (как в скобках на карте), при «умеренно» движок берёт ±1 от обычного; `fixed` — поправка при любой силе (написана не в скобках). Бонус тега культуры на этих картах не добавляется. Нулевая точка оси Патриархат ↔ Матриархат — «нейтрально (0)».

Ошибка нумерации в документе (два одинаковых номера) не ломает сборку: повтор получает букву (`17б`), а таблица `RENUMBER` в сборщике даёт ему номер, назначенный автором («Лотерейный билет» — `культура.61`).

## Колода «Класс»

Шесть стопок в одном файле, нумерация в каждой своя: id `класс.народ.01`, у карты поле `cls` — чья стопка. «Все» отрезки здесь — Юность … Старость. Стопки переводятся по очереди: сборщик пропускает стопку, для которой ещё нет разбора.

## Развилки

Название — из колонки «Развилка», оригинал — из «Пути», тип всегда «Р». Напечатанные на поле развилки несут поле `cell` («на поле, клетка 8»). «+1 к Стажу» на картах (`add: {"Стаж": 1}`) — заполненная отметка найма. Вступительные на «Образовании» — единственная проверка со сложностью 16.

## Институты (Тюрьма, Психбольница, Кабала)

Номеров в документе нет — карты нумеруются по порядку (общие, затем по стране). Текста у карт нет. Фильтр по стране сохраняется в `filter`, а условие — в `requires`. Тип карты выводится из разбора: выбор — Р, проверка — П, иначе Б.

## Мир и Смута

Карта Мира: `scope` (охват из документа), `target` — какую страну бьёт карта, `country` — что происходит со страной (условия проверяются на ней; шаг `stab` — стабильность ±n), `effect` — что получает каждый игрок (`inTarget` — живёт ли он в целевой стране). Оттепель (О1–О4) — `мир.о1` … с `requires: {mode: "род"}`.

Карта Смуты: `effect` — строка «Для всех», `sides.win / lose / neutral` — строки победителей, проигравших и нейтралов. Условие `side` — сторона игрока, `chose` — вариант, выбранный игроком на этой же карте. Общее правило Смуты о тюрьме меняется правилом `правило тюрьмы`.

## Проверка

```json
{"stat": "Интеллект", "dc": 15, "mods": [{"if": {"p": "Положение", "gte": 2}, "dc": 12}]}
```

- `stat` — одна характеристика или список: игрок бросает лучшей («Интеллект или Харизма 12»).
- `or` — другие характеристики со своей сложностью («Смекалка 12 или Сила 15»).
- `mods` — поправки по условиям (без `if` — всегда): `dc` (новая сложность), `add` (±к броску), `adv`/`dis` (преимущество/помеха), `auto` (автоуспех); `spend` — поправка от козыря, игрок решает, тратить ли его.
- Поправки по тегам карты (культура, характер, предметы, класс, идеология) не пишутся: их считает движок. Потолок ±3 — тоже его забота.

## Условия

| Условие | Пример |
|---|---|
| Число | `{"p": "Финансы", "lte": -1}`, `{"p": "Харизма", "gte": 7}`, `{"p": "Стаж", "gte": 10}` |
| Позиция страны | `{"pos": ["ядро", "полупериферия"]}` |
| Идеология | `{"ideo": ["Госсоциализм"]}`, группы: `"демократии"`, `"диктатуры"` |
| Культура | `{"culture": "Традиция"}` — клонится к полюсу; `"strong": true` — только «сильно»; `{"neutral": "Традиция"}` — ось нейтральна |
| Характер | `{"char": "Выдержка"}` |
| Класс, пол, чужак | `{"cls": ["Мафия", "Олигархи"]}`, `{"sex": "ж"}`, `{"minority": true}` |
| Предмет | `{"has": "Учитель"}`; любой предмет вида — `{"hasKind": "вещь"}`. «Друг» — любой друг, включая «Друга детства»; «Диплом» выполняется и «Престижным дипломом» |
| Отрезок, журнал | `{"seg": ["Старость"]}`, `{"flag": "..."}`. Отметку `"Армия, война"` движок ставит сам: был в классе Армия или застал войну в стране с Юности |
| Основная культура страны (она же география) | `{"mainCulture": ["Карвенцы", "Олейцы"]}` — Большое озеро; Эшвины — болота; Сарды — ледник |
| Диаспора без своих | `{"diaspora": true}` — культуры игрока нет в стране ни как основной, ни как меньшинства |
| Смысл жизни, смена власти | `{"meaning": "найден"}` / `"серость"`, `{"powerChanged": true}` — в стране уже была смена власти |
| Место рынка в этом отрезке | `{"visited": "Салон красоты"}` |
| Эмигрант | `{"emigrant": true}` — живёт не в стране рождения |
| Партнёр другой культуры или класса; число предметов | `{"partnerDiff": "класс"}`, `{"count": "Ребёнок", "gte": 2}` |
| Своё дело | `{"ownBusiness": true}` — лежит карта дела; дело даёт `{"gain": "Кафе на углу"}`, теряется правилами `дело прогорело` / `дело в сброс`. `"Стаж найма"` — Стаж без пустых отметок «Дела» (для пенсии и «Проводов») |
| Пол по оси Патриархат ↔ Матриархат | `{"sexFavored": true}` — в преимуществе, `false` — в помехе; при 0 ни то ни другое (`{"neutral": "Патриархат"}`) |
| Партнёр не из большинства | `{"partnerMinority": true}` |
| Класс семьи, война | `{"familyCls": ["Армия"]}` — класс при рождении; `{"war": true}` — страна воюет |
| Живёт не один | `{"notAlone": true}` — Супруг(а), Партнёр, отметка «Не один» или сиделка в этот ход |
| Страна: стабильность, смена власти | `{"stability": {"lte": 3}}`, `{"powerChanged": true, "inSeg": true}` — в этом отрезке |
| Страна: классы | `{"clsRole": "доминирующий"}` — класс игрока; `{"alienated": ["Народ"]}` — отчуждённый класс страны |
| Страна: состав и соседи | `{"multicultural": true}`, `{"relation": "вражда"}` / `"союз"`, `{"fromHostile": true}` — эмигрант из враждебной страны |
| Игрок: мода, культура, дело, работа | `{"inFashion": true}` — раса в моде; `{"cultureIs": ["Сарды"]}`; `{"ownBusiness": true}`; `{"working": true}` — ставил Стаж в этом отрезке или учится |
| Призыв | `{"draft": true}` — в стране призыв и он касается игрока (считает движок) |
| Срок за тег | `{"sentenceTag": "#политика"}` — игрок в институте за событие с этим тегом |
| Мир и Смута | `{"inTarget": true}`, `{"draftable": true}` — подлежит призыву, `{"formerDominant": true}`, `{"side": "проигравшие"}`, `{"chose": "подписать"}` |
| Режим партии | `{"mode": "род"}` — например, отметки в Летописи |
| Логика | `{"all": [...]}`, `{"any": [...]}`, `{"not": ...}` |

Общее правило записи: условие после броска d6 через «;» («d6 6 — +1 Мудрость; в культуре Фамилизма ещё +1 псих.») от броска не зависит и срабатывает при любом результате.

«Партнёр» не приходит, если уже есть Партнёр или Супруг(а) (остальные эффекты карты срабатывают) — это делает движок, на картах не пишется.

Финансы, Положение и Сплочённость — шкалы семьи (−3…+3); «Финансы» и «Финансы семьи» на картах — одно и то же.

## Как переводится колода

1. Claude переводит эффекты колоды в шаги и пишет вопросы к спорным местам.
2. `npm run deck -- <колода> "<заголовок раздела>" <разбор.json>` берёт название, текст, тип, теги и оригинал
   дословно из `reference/docs/events.md` и собирает файл колоды. Схема проверяет каждую карту.
   Без файла разбора команда обновляет колоду из документа и сохраняет уже сделанный разбор.
3. `npm test` проверяет имена предметов по каталогу, броски d6, сложности, соответствие типа карты разбору.
4. Август смотрит спорные карты в просмотрщике и отвечает; разбор правится.

## Смыслы

Файл `src/data/meanings.json` собирается командой `npx tsx tools/build-meanings.ts` из `reference/docs/meanings.md`.
Названия, девизы, требования и тексты условий берутся дословно. Типовые условия («Стаж 10+», «Харизма 6+»,
«Класс Народ», «Войти в Старость в браке») переводятся по образцам, остальные — по словарю `tools/meaning-conds.ts`.
Условие без перевода останавливает сборку.

```json
{
  "id": "смысл.04", "deck": "Случайные", "n": 4, "title": "Найти любовь", "difficulty": "Средний",
  "conds": [
    {"text": "Войти в Зрелость в браке", "kind": "соб.", "points": 2,
     "cond": {"atEntry": "Зрелость", "cond": {"has": "Супруг(а)"}}}
  ]
}
```

| Тип условия | Как считает движок |
|---|---|
| сост. | Очки есть, пока условие выполняется |
| соб. | Один раз и навсегда: движок с рождения помнит, что условие хоть раз выполнилось |
| итог | Проверяется в момент смерти |

Условия смыслов, которых нет у карт событий:

| Условие | Пример |
|---|---|
| Счётчик журнала жизни | `{"log": "эмиграция", "gte": 1}`; «никогда» — `{"log": "эмиграция", "lte": 0}`. Список счётчиков — `LOG_EVENTS` в схеме: это всё, что движок обязан записывать |
| Значение сейчас | `{"val": "пенсия", "gte": 2}`; также связи, вещи, козыри, друзья, аккультурация |
| При входе в отрезок | `{"atEntry": "Старость", "cond": …}` |
| Дожить до отрезка | `{"reached": "Древность"}` |
| Класс относительно рождения | `{"clsVsBirth": "выше"}` по лестнице Народ < Армия = Полиция = Интеллигенция < Мафия < Олигархи |
| Несколько предметов сразу | `{"countOf": ["Диплом", "Значок", …], "gte": 2}` |
| Класс пары, институт | `{"partnerCls": ["Олигархи"]}`, `{"inInst": "тюрьма"}` |

Отметки журнала, которые ставят сами карты событий: «сказал в #раскрытие» (Юность № 8, Культура № 29),
«спрятал соседа» (Судьба № 7), «рыжего кота прогнали», «Не один», «рабочий профиль».
Отметки, которые ставит движок: «Армия, война», «Побывать на войне».
