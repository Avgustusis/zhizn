# Фронт: события войны

140 событий фронта: 14 клеток трека × d10. Они напечатаны прямо на поле «Фронт», карт нет; правила — в концепции, раздел «Война». Солдат читает таблицу клетки, где стоит метка, со своего края трека; офицер — строку «Офицер», если она есть. На клетке «Разгром» (−7) событий нет: там война кончается.

**Как читать.** Черта в скобках после варианта обязывает: у кого она есть (умеренно или сильно), тот выбирает этот вариант; «сильное Самолюбие» — только при сильной черте. Подходят два варианта — выбор из них, ни один — выбор свободный. «Самолюбие: …» без слова «Остальные» — добавка тем, у кого эта черта; со словом «Остальные» — у названных своё вместо общего. **Награда** — Положение семьи +1, только тому, кто в этот ход шёл «В атаку». **Фронт ±1** — метка на клетку к противнику или к своим. **Отпуск по ранению** — следующий ход дома. **Плен** — d3 хода по колоде «Тюрьма» без «Судимости», потом домой. **Трибунал** — тюрьма со «Судимостью». **«Кровь на руках»** — отметка в журнале жизни навсегда. «Беречь себя»: каждая потеря физ. на 1 меньше.

**Клетка «ПОБЕДА!»** читается дважды: при штурме города, который держит госсоциализм («Ни шагу назад!»), и один раз каждым солдатом-победителем, когда война выиграна. Защитники города при штурме читают «Последний рубеж».
