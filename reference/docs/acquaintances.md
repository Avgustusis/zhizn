# Колоды знакомств

Семнадцать зданий города, по 10 встреч в каждом (170 карт). Правила — в концепции, раздел «Город и знакомства». Встреча сдвигает характер на шаг к одному из двух полюсов карты (или к нулю по одной из этих осей). 📇 — бросок на «Знакомого»: d6 4–6, в Центре 3–6. Карта уходит под низ колоды.
