# Колода смыслов

Все карты смысла жизни для игры «Жизнь». Правила (счастье, поиск смысла, шаблон карты, правила формулировок) — в [концепции](https://claude.ai/artifact/LMNt9m8tJps79dxjzd1nR2), здесь только сами карты.

**Порядок:** сначала серая карта, потом Случайные смыслы (70), потом смыслы Династий (30). Всего 101 карта.

**Пометки условий:** *сост.* — действует, пока выполняется; *соб.* — один раз и навсегда; *итог* — проверяется в момент смерти. «Выше / не ниже класса рождения» считается по лестнице классов: Народ < Армия = Полиция = Интеллигенция < Мафия < Олигархи. Теги смысла — только из каталога тегов концепции.

**Сделано:** Серость 1/1 · Случайные 70/70 · Династии 30/30. Карты 11–15 — необычные смыслы; их ровно 5 на колоду (5%).
