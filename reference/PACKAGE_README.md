## Что в пакете

```
README.md            этот файл
docs/
  concept.md         концепция (свод правил), снимок
  events.md          все колоды событий, около 700 карт
  meanings.md        101 карта смысла
  items.md           предметы: каталог, «Верхи», «Дно»
  heirs.md           12 стандартных наследников
  style.md           стиль и сеттинг
  report.md          отчёты всех прогонов симуляции
lore/
  letter_ru.md       текст книги правил («Письмо Предшественника»), RU
  letter_pl.md       то же, PL
engine/              рабочая симуляция на Python — по сути готовый движок правил
  sim3.py            партия целиком: поле, рынки, мир, эпохи, «Род», ИИ-игроки
  engine3.py         разбор текста карт в эффекты и проверка условий
  meanings.py        разбор карт смысла и подсчёт счастья
  meanings.md        карты смысла в формате, который читает meanings.py
  cards_v4.json      все карты событий, разобранные из документа колод
  pilot16.json       пилот для ИИ: средние значения карт из прошлого прогона
  mkpilot.py         строит новый пилот из результата прогона
  analyze3.py, audit.py  разбор результатов (в audit.py пути к файлам прогонов прописаны вручную)
components/          40 макетов из холста компонентов (.dc.html) — образец вида и раскладки
```

Запуск движка (Python 3, без сторонних библиотек):

```
cd engine
PILOT=pilot16.json python3 sim3.py 600 50 out.json          # «Поколение»: 600 партий, 50 кругов
MODE=rod PILOT=pilot16.json python3 sim3.py 600 100 out.json  # «Род» на 20 мировых ходов (150 — на 30)
```

Правила включаются флагами окружения в начале `sim3.py`. Значения по умолчанию соответствуют утверждённым правилам.

## Состояние правил

После 10 прогонов (последний — 600 партий в трёх режимах) проблем уровня прошлых прогонов не осталось, и правила признаны условно готовыми к полевым испытаниям. Последние утверждённые изменения:

- Развилка больше не сжигает ход: после неё фишка проходит остаток клеток. Напечатаны четыре развилки: «Образование» (последняя клетка Юности), «Эмиграция» (Молодость, 8), «Партнёрство» (Молодость, 20), «Ребёнок» (Зрелость, 10).
- **За ход:** один большой обмен или работа плюс один малый обмен, только после хода.
- **Взрослый рынок работает с Молодости** (решено 11.11), как и считала симуляция. В Молодости сверх обычного обмена можно одно решение Рынка молодости за ход, не больше трёх за Молодость. Студенты (путь А «Образования») первые 15 клеток Молодости из работ берут только Подработку, без Стажа.
- **Износ от работы — по d6.**
  - Подработка: 1–4 — −1 к большему здоровью.
  - Работа: 1–2 — −1/−1; 3–4 — −1 к «своему» здоровью, на втором d6 5–6 — к другому.
  - Переработка: 1–2 — −2/−2; 3–4 — −1/−1; 5–6 — −1 к своему.
  - «Своё» здоровье: у Народа и Армии — физическое; у Интеллигенции, Полиции и Олигархов — психическое. Мафия платит риском.
  - Здоровье на −8 и ниже износ не трогает.
- **Периферия:** лавки по базовой цене 2, малый обмен в больнице 1, у психолога 2.
- **Серость:** 6 условий по 0,5 очка и 4 по 1, максимум 7. «Жизнью со смыслом» она не считается.
- **Эпохи:** «Эпоха смыслов» — с 60% жизней со смыслом. Пороги особых эпох даны на 10 мировых ходов, в «Роде» удваиваются и утраиваются.
- **Ещё:** вступительные экзамены — сложность 16; кабала начинается с −15; вход в Древность — 3d6 + физ. ≥ 12 (ядро +1, периферия −2).
- **Расы стран при подготовке:** d8, 1–7 по порядку, 8 — «удача»: бросающий сам выбирает расу. Раса персонажа берётся из его страны (d10).

## Чего движок не моделирует

Цифровой версии придётся реализовать это впервые:

- оси характера;
- бонусы предметов по тегам;
- колоды «Верхи» и «Дно»;
- Рынок молодости (в ИИ упрощён);
- модификаторы культуры;
- правило привилегий.

Около 4,5 условия за жизнь (примерно 7% текстов карт) `engine3.py` не понимает и решает монеткой.

## Открытые вопросы

- Подростковых срывов после урезания психики стало больше: 7,9% жизней.
- Ловкость — самая низкая характеристика, а проверяют её часто.
- Перевес в победах: у рождённых в Мафии 35% против 23% у Народа; у Династий 32% против 27% у Случайных. На поле стоит присмотреться.
- Карта «Детям — лучшее», возможно, всё ещё сильная (+1,5 к среднему по 20 жизням).

## Предложенный план цифровой версии

Всё ниже — предложение. Решения принимает Август.

1. **Репозиторий на GitHub.** Без него код теряется между сессиями.
2. **Стек:** веб, TypeScript, одна страница. Одна программа для компьютера и телефона, без установки, играть по ссылке.
3. **Главная техническая задача — данные карт.** Сейчас эффекты разбираются из текста регулярными выражениями, и часть условий не распознаётся. Для приложения нужен формат карт с явными эффектами и условиями, например JSON со схемой. Переводить карты — полуавтоматически, по `cards_v4.json` и документу колод, с проверкой спорных карт.
4. **Первая версия:**
   - одно устройство, 2–4 игрока по очереди («передай телефон») плюс ИИ-соперники на логике из `sim3.py`;
   - простой интерфейс без иллюстраций;
   - партию «Поколение» можно пройти от рождения до Итога мира.
5. **Дальше:** «Род», сохранение партии, иллюстрации в стиле из `docs/style.md`, звук, затем сетевая игра и магазины приложений.

Уровни усилий Claude, о которых договорились:
- архитектура, перенос движка, первая играбельная версия — high (max только для первого проектирования);
- интерфейс и обычные правки — medium;
- мелочи — low;
- трудные баги — high или max.
